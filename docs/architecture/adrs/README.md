# Architecture Decision Records

This directory stores short decision records for structural choices that affect multiple milestones.

Use ADRs for decisions such as:

- runtime backend selection
- session ownership model
- artifact manifest format
- docs source-of-truth
- CEF parity rules

Recommended format:

1. Context
2. Decision
3. Consequences
